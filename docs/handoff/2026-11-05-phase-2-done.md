## Gotchas found this session

- **Turbopack dev missed a `globals.css` edit** (Windows). The `.tsx` edits hot-reloaded, but the root stylesheet kept serving the old base layer, even after `touch`. Tailwind compiled it correctly outside the server. A dev-server restart fixes it. If a CSS change "doesn't work", grep the served `/_next/static/chunks/*.css` before debugging the CSS itself.
- Removing an element with `display: none` while it anchors a Base UI popup sends the popup to (0,0). Hover/focus-only controls that open popups must fade, not unmount or `hidden`.
- A `dark:` ring/bg variant on a base class beats a plain utility added later. Override with a `dark:` twin.
