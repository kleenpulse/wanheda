## Things the spike (T74) must settle
- Origin host: `localhost` vs `127.0.0.1`. Passkeys reject an IP address as the site ID; the GitHub OAuth callback and `BETTER_AUTH_URL` must match. A desktop GitHub OAuth app may be needed (owner action).
- Raven's bootstrap parses `const nextConfig = {...}` out of the standalone `server.js` and calls Next internals: confirm it still holds on Next 16.4.5.
- Raven's `desktop:setup` runs `node desktop/node_modules/electron/install.js`. Our tripwire fails any `package.json` script that runs `node` on anything but one `.ts` file, so Wanheda needs its own checksum-checked fetch script (V76).
- Native Piper speed vs WASM (≥ 3× gate), and addon vs CLI.
- Global media keys vs Chromium's own media session.

## Raven gotchas to carry over
- `Bun.build` bakes `__dirname` in as the source folder: use `app.getAppPath()` and `process.cwd()`.
- `ELECTRON_RUN_AS_NODE` leaks from VS Code terminals: delete it in the dev, stage and build scripts.
- electron-builder drops a root `node_modules` inside `extraResources`: add it as a separate entry.
- Turbopack leaves symlinks and junctions in `.next/standalone`: copy with `dereference`, and verify there are none left.
- Windows: notifications need the installer's Start-menu shortcut with a matching AppUserModelID; protocols are registered at every start; use the full `reg.exe` path; the updater must wait until the server has stopped.
- `resources/server` is outside asar integrity (it relies on the per-user AppData permissions).
